v1.4.1
Save compatible. Can be added to existing saves.

- Fixed colony items not appearing in the Items tab when another mod alters their item data.

v1.4.0
Save compatible. Can be added to existing saves.

- Fixed detached Flotilla ships sometimes losing hullmods (though doesn't fix existing saves).
- A detached Flotilla despawned by another mod now counts destroyed.
- Added intel messages when a detached Flotilla loses ships or is destroyed.
- The Catalytic Core now reduces ore and transplutonic ore inputs instead of fuel volatiles.
- The Synchrotron Core now reduces fuel volatiles input, replacing its fuel yield bonus.
- Added a Trivial difficulty meant to be more powerful than a colony.
- Added a setting for the hullmods' ordnance point cost.
- Added optional handicap settings that lower top speed, fire rate, and combat readiness.
- Added a close button to the Flotilla screen, and Escape now closes it instead of the whole refit screen.
- Fixed the Flotilla screen sometimes not appearing when opened from the refit screen.

v1.3.0
Save compatible. Can be added to existing saves.

- Added an autoforge yield multiplier setting.
- You can now drag the top bar to move it around.
- Fixed a bug where the production multiplier setting didn't apply to every allocation.

v1.2.0
Save compatible. Can be added to existing saves.

- Added a revert button, which notably can be used to undo the balance buttons if you don't like them. The balance button will also say how much space/money it takes.
- Works will now show the actual amount of space they take if they require a percentage.

v1.1.0
Save compatible. Can be added to existing saves.

- Autoforge can now build fighter wings.
- Colony items installation should be fixed.
- Fixed the refit screen ignoring Expanded Cargo Holds and Additional Berthing.
- Splitting off the Flotilla from the management screen now tells you what your cargo, fuel and crew capacity become once those ships leave.
- You can now manually set how much cargo and quarters each ship converts to the Flotilla (including the flagship). This is actually a substantial buff. I might need to nerf it.
- The Nomad Cargo, Quarters and Full Conversion hullmods are deprecated.
- Round-the-Clock Yards' bonus now ends as soon as you scrap the Work, instead of lingering for a few days.
- Added support for other mods adding their own Works, colony items, and allocations. See MODDING.md.
- Added cross-mod interactions with Captain's Quarters.
- Rewrote the Manual

v1.0.1
Save compatible. Can be added to existing saves.

- You can now search and page through the autoforge build list.
- Fixed the Nomad Flagship hullmod description.
- Added a setting to open management from the Intel screen instead of the bottom bar, for cross-mod compatibility.

v1.0.0
Can be added to existing saves.

- Initial release.
